
# Сервис заявок

Учебный проект для практической работы по настройке CI/CD.

## Возможности
- Создание заявок.
- Проверка приоритета заявки.
- Поиск заявки по идентификатору.
- Получение списка заявок.

## Допустимые приоритеты
- low — низкий;
- medium — средний;
- high — высокий.

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```
